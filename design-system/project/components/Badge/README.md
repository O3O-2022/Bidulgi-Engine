# Badge

Small labels: language pills, status pills and origin badges.

- Pill: 18px, `radius-pill`, `sunk` fill, `badge` text. Language pills sit before file names; status pills always carry a word (`OK`, `WARN`, `ERROR`) beside the color.
- Origin badges (Unity `source-unity`, Unreal `source-unreal`, Blender `source-blender`, native `accent` on `accent-soft`) belong to planning docs and mockups only, never to the shipped editor.
- Provide: the text. Color comes from the variant class.
- Do not use a badge as a button, or show status by color alone.
