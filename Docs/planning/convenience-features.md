# 추가 편의 기능 (2026-11-23)

이미 계획된 것(명령 팔레트, 자동 저장·크래시 복구, 에디터 한국어, 씬 diff, 게임 현지화 — [review-2026-11-20](review-2026-11-20.md), [backlog](backlog.md))에 더해, 아직 없던 편의 기능을 정리합니다.
각 기능은 바탕이 되는 시스템이 생기는 단계에 함께 만듭니다. 순서와 완료 조건은 [QUEUE](../QUEUE.md)에 있습니다.

## 1순위 — 매일 쓰는 기능

| 기능 | 내용 | 바탕 | 단계 |
|---|---|---|---|
| **Undo 기록 패널** | 명령 버스 기록을 목록으로 표시, 클릭하면 그 시점으로 이동. AI·스크립트·사람 편집을 아이콘으로 구분, AI가 한 번에 한 묶음은 접힌 그룹 | 명령 버스 | M1 |
| **참조 찾기 / 안 쓰는 에셋 찾기** | 에셋 우클릭 → "어디서 쓰이나"(씬·프리팹·머티리얼·스크립트), 프로젝트 전체에서 참조 없는 에셋 목록, 지우기 전에 경고. `bdg refs <에셋>`, `bdg unused` | 에셋 DB(GUID) | M2 |
| **여러 오브젝트 동시 편집** | 여러 개 선택 시 Inspector가 공통 컴포넌트만 표시, 값이 다르면 "—", 한 번에 수정(명령 하나 → Undo 한 번) | 리플렉션 + 명령 버스 | M2 |
| **컴포넌트 값 복사·붙여넣기, 프리셋** | 컴포넌트 메뉴 → 값 복사 / 붙여넣기 / 새 컴포넌트로 붙여넣기. 프리셋은 `.preset` 텍스트 파일 | 리플렉션 | M2 |
| **스냅·정렬·측정** | 그리드 스냅(단위 설정), 꼭짓점 스냅, 표면에 붙이기, 여러 개 정렬·간격 맞추기, 거리 측정 자 | 기즈모 | M3 |
| **콘솔 개선** | 오류 클릭 → 해당 코드 줄 열기(C#·C++·Lua) 또는 Graph 노드로 이동, 같은 메시지 묶기(×12), 수준·출처 필터, 검색 | 스크립팅 | M4~M5 |

## 2순위 — 개발 흐름

| 기능 | 내용 | 단계 |
|---|---|---|
| **플레이 모드 도구** | 실행 중 에디터 테두리 색(편집이 사라질 수 있다는 경고), 시간 배율 슬라이더 0.1x~4x, 한 프레임씩 진행, 실행 중 바꾼 값 "유지" 표시 | M3 |
| **디버그 그리기 API** | `Debug.DrawLine/Ray/Box/Sphere/Text3D(…, seconds)` — 모든 언어 같은 이름, 배포 빌드에서 제거 | M4 |
| **찾아 바꾸기** | 씬·프리팹 전체에서 참조 교체(머티리얼·프리팹·스크립트), 일괄 이름 바꾸기(번호 붙이기, 접두어) | M2 후반 |
| **git 상태 표시** | Project 패널에 변경·새 파일·충돌 표시, Hierarchy에 바뀐 오브젝트 표시, 오브젝트 단위 "마지막으로 바꾼 사람" | 1.0 |
| **모바일 기기 미리보기** | USB·Wi-Fi로 휴대폰에서 바로 실행, 에디터에서 고친 값 실시간 반영, 터치·안전 영역·발열 확인 | 1.0 (Android) |
| **녹화·캡처 도구** | 에디터·게임 화면을 영상·GIF로 저장, 필름크래프트 프로젝트로 내보내기(장면별 클립 + 자막 자리) | 1.0 |

## 3순위 — 비둘기 엔진만의 강점

| 기능 | 내용 | 단계 |
|---|---|---|
| **에디터 안 AI 패널** | 채팅 요청 → 바뀔 내용을 diff로 미리 보기 → 승인 시 명령 버스로 적용(Undo 한 번). 콘솔 오류에 "AI에게 설명" 버튼. AI 끄기 스위치·사용 기록 | M6 (MCP 이후) |
| **프로젝트 상태 점검** | `bdg doctor` + 에디터 화면: 깨진 참조, 너무 큰 텍스처, 비싼 셰이더, 품질 단계 예산 초과, 라이선스 누락을 한 화면에, 항목마다 "고치기" | 1.0 |
| **테마 편집기** | 토큰을 색상 선택기로 편집, 실시간 반영, 프로젝트별 테마 저장(`ProjectSettings/Theme.json`) | M1~M2 |
| **처음 사용자 안내** | 첫 실행 5분 튜토리얼(오브젝트 놓기 → 스크립트 붙이기 → 실행), 패널마다 "?" 버튼으로 문서 연결, 유니티·언리얼 용어 검색 대응표 | 1.0 |

## 버그 제보 보완 (같은 날 정리한 단점)

| 항목 | 내용 | 단계 |
|---|---|---|
| 단축키 변경 | F12는 Windows 디버거 중단 키와 겹침 → `Ctrl+Shift+B`로 바꾸고 단축키 프리셋에서 변경 가능하게 | M0 손질 (0-14 완료) |
| 개인 정보 치환 | 보고서의 사용자 폴더 경로를 `%USERPROFILE%`로 바꾸고, 첨부 전 미리보기 | M0 손질 (0-14 완료: 폴더를 먼저 열어 확인) |
| 에디터 전용 | 게임 빌드에는 넣지 않음. 게임용 제보 대상(자기 저장소·이메일·끄기)은 프로젝트 설정에서 | M7 빌드 |
| 크래시 보고 | crashpad로 튕길 때 같은 폴더 자동 생성, 다음 실행 때 "제보할까요?" | M1 |
| 보고서 정리 | 30일 지난 `BugReports/` 자동 삭제, PNG 압축(stb_image_write 등)으로 용량 축소 | M0 손질 |

# 2차 추가 (2026-11-23) — 게임 제작 도구와 기본 기능

## 제작 도구

| 기능 | 내용 | 단계 |
|---|---|---|
| **그레이박스(블록아웃) 도구** | 에디터 안에서 상자·계단·경사로·원기둥을 만들고 면을 밀고 당기기(ProBuilder 방식). 결과는 메시 + 충돌체, 나중에 블렌더로 내보내기 | M3 후반 |
| **데이터 테이블** | 행 구조(리플렉션 구조체)를 정하고 스프레드시트처럼 편집. `Data/Weapons.table.jsonl`(한 줄에 한 행), CSV 가져오기·내보내기, 스크립트에서 `Data.Get<Weapon>("rifle")` | M4 |
| **스플라인 도구** | 곡선 편집(점 추가·핸들), 곡선 따라 메시 늘이기·배치(길·레일·울타리), 이동 경로 | M6 |
| **끌어다 놓기 임포트 + 자동 다시 가져오기** | 탐색기에서 끌어다 놓기, 원본 변경 감지 → 재임포트, `.blend` 직접 가져오기(블렌더 백그라운드 실행) | M2~M3 |
| **대화·퀘스트 그래프** | Graph 확장 노드(대사, 선택지, 조건, 퀘스트 단계), 현지화 키 연동. 패키지로 제공 | 1.0 이후 |
| **실행 중 상태 디버거** | 플레이 중 상태 머신·애니메이션 그래프·Graph 실행 흐름을 실시간 강조, 변수 값 표시 | M5~M7 |

## 게임 기본 기능 (템플릿·패키지)

| 기능 | 내용 | 단계 |
|---|---|---|
| **게임 설정 메뉴** | 그래픽 품질(5단계), 해상도·창 모드, 키 재설정(입력 액션), 음량, 언어, 자막. 모든 템플릿에 기본 포함 | 1.0 |
| **세이브·로드** | `[Save]` 필드 자동 직렬화, 슬롯, 형식 버전 변환, 클라우드 저장 연결 지점 (`SaveGame.Save("slot1")`) | M6 |
| **게임 접근성** | 자막 시스템, 색각 이상 필터, 글자 크기, 조작 단순화(길게 누르기 → 토글) | 1.0 |
| **플랫폼 서비스** | Steam 업적·리더보드·클라우드 저장(Steamworks), 이후 Epic·모바일 | 1.0 이후 (패키지) |
