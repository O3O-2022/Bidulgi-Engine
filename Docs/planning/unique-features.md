# 다른 상용 엔진에 없는 기능

비교 기준은 **유니티, 언리얼, 고도의 기본 기능**입니다. 외부 플러그인으로 비슷한 것을 만들 수 있는 경우도 있지만, 엔진 설계에 처음부터 들어 있는 것은 아닙니다.

표시: ★ 이 엔진의 핵심 차별점 · ✓ 기획 문서에 있음 · ✚ 2026-11-20 새로 채택 (기능 문서와 백로그에 반영됨)

---

## A. AI와 함께 만드는 기능

| | 기능 | 다른 엔진은 | 상태 |
|---|---|---|---|
| ★ | **사람과 AI가 같은 명령으로 편집.** UI 버튼, 터미널, AI가 같은 명령 버스를 거치고, AI가 한 작업은 Ctrl+Z 한 번으로 되돌림. 기록에 출처(UI/터미널/에이전트) 표시 | AI 연동은 외부 플러그인이나 파일 직접 수정 | ✓ |
| ★ | **토큰을 아끼는 텍스트 씬.** 기본값 생략, 오브젝트당 한 줄, 압축 보기(`bdg view`), 상태 표시줄에 토큰 수 | 유니티 YAML은 길고, 언리얼 레벨은 바이너리 | ✓ |
| ★ | **AI 안내 파일 자동 갱신.** 프로젝트의 `AGENTS.md`에 기본 언어, 명령, 컴포넌트 요약을 엔진이 계속 써 둠 | 없음 | ✓ |
| | `bdg explain` — 이 오브젝트가 왜 이렇게 움직이는지(붙은 스크립트, 그래프, 애니메이션, 설정) 텍스트로 설명 | 없음 | ✓ |
| ✚ | **"왜 안 보이지?" 진단.** 오브젝트를 고르고 버튼 하나로 화면에 안 나오는 이유를 순서대로 검사 (비활성, 카메라 밖, 레이어 컬링, 머티리얼 누락, 크기 0, 다른 물체에 가림) | 사람이 하나씩 확인 | 채택 (2026-11-20) |
| ✚ | **자연어 검색.** Hierarchy 검색창에 "체력 50 이하 고블린"을 쓰면 `bdg query`로 바꿔 실행하고, 만들어진 쿼리도 보여 줌 | 이름·타입 검색 위주 | 채택 (2026-11-20) |

## B. 그래프와 스크립팅

| | 기능 | 다른 엔진은 | 상태 |
|---|---|---|---|
| ★ | **텍스트로 저장되는 그래프.** git diff와 병합이 되고, AI가 읽고 씀 | 언리얼 블루프린트는 바이너리라 diff·병합 불가 | ✓ |
| ★ | **의사코드 ↔ 그래프 변환.** 그래프를 의사코드로 읽고, 의사코드를 쓰면 그래프가 됨 | 없음 | ✓ |
| | 그래프를 C# 코드로 내보내기 (그래프로 시작해 코드로 옮겨 갈 때) | 언리얼 C++ 변환(Nativization)은 UE5에서 제거됨 | ✓ |
| | 그래프 **실행 기록 되감기** (최근 N프레임의 실행 흐름을 거꾸로 돌려 보기) | 브레이크포인트 중심 | ✓ |
| ★ | **언어 5종이 한 프로젝트에서 동시에** (C#, C++, Lua, Python, 그래프). 그래프를 고치면 각 언어용 타입 프록시가 생성되어 오타가 컴파일 에러로 드러남 | 엔진마다 1~2개 언어 | ✓ |
| | 애니메이션 그래프에서 스레드 안전하지 않은 함수를 쓰면 **컴파일 에러** | 언리얼은 실행 중 경고 | ✓ |
| | 언어를 넘는 호출 스택 (C# → 애니메이션 Notify → 그래프를 한 스택으로) | 언어별로 따로 | ✓ |
| ✚ | **플레이 녹화 → 자동 테스트.** Play 중 입력과 결과를 녹화해 `bdg test`용 테스트로 저장. 고친 뒤 같은 플레이를 자동으로 다시 돌려 비교 | 테스트는 사람이 따로 작성 | 채택 (2026-11-20) |

## C. 에디터 편의

| | 기능 | 다른 엔진은 | 상태 |
|---|---|---|---|
| | **복사 = 텍스트.** 오브젝트를 Ctrl+C 하면 JSON 한 줄. 채팅이나 문서에 붙이고, 받은 텍스트를 Ctrl+V로 씬에 다시 넣기 | 유니티·언리얼도 텍스트로 복사되지만 길고 내부 형식이라 사람이 읽기 어려움 | ✓ |
| | Inspector의 **Text 탭** — 지금 고친 값이 파일에 어떻게 저장되는지 바로 보기 | 없음 | ✓ |
| | 프로젝트 설정 창에서 **저장되는 설정 파일을 실시간 미리보기** (플랫폼별 덮어쓰기 포함) | 설정 파일은 따로 열어야 함 | ✓ |
| | 위젯 Details에 **"이 위젯을 쓰는 곳"** (Screen/World/Camera별) | 참조 검색을 따로 실행 | ✓ |
| | 스크립트 목록을 **폴더 트리 / 언어별**로 전환, 전체 경로 표시 | 언어가 하나라 언어별 보기가 없음 | ✓ (시안 v0.2) |
| ✚ | **편집 중 플랫폼 예산 표시.** 대상 플랫폼(예: 저사양 Android)의 Draw call·메모리·삼각형 예산을 뷰포트 구석에 막대로 표시하고, 넘으면 원인 오브젝트를 강조 | 프로파일링은 실행해서 따로 | 채택 (2026-11-20) |
| ✚ | **UI 자동 점검.** UI Designer에서 글자 대비, 최소 글자 크기, 터치 영역 크기(모바일), 가장 긴 번역문이 넘치는지 저장할 때 검사 | 따로 도구가 필요 | 채택 (2026-11-20) |

## D. 협업과 프로젝트 관리

| | 기능 | 다른 엔진은 | 상태 |
|---|---|---|---|
| ★ | **id 기준 씬 병합.** JSONL 씬 + 전용 git merge 드라이버로, 같은 오브젝트를 동시에 고친 경우만 충돌 | 씬 파일 충돌이 흔한 문제 | ✓ (검토 문서) |
| | 큰 씬을 **레이어 파일로 분할** → 여러 사람·에이전트가 다른 레이어를 동시에 편집 | 언리얼 One File Per Actor는 파일이 너무 많고 바이너리 | ✓ |
| ✚ | **에셋 출처·라이선스 추적.** `.meta`에 출처 URL과 라이선스를 적어 두면, 빌드할 때 크레디트 화면과 라이선스 목록을 자동 생성하고 상업 사용 불가 에셋이 들어가면 경고 | 없음 | 채택 (2026-11-20) |
| ✚ | **변경 영향 미리보기.** 명령 실행 전에 "이 명령은 오브젝트 37개와 프리팹 2개를 바꿉니다"처럼 범위를 보여 주고, AI 명령이면 승인 단계에서 표시 | 실행 후 확인 | 채택 (2026-11-20) |

## 이 엔진을 한마디로 설명할 기능 TOP 5

1. 사람과 AI가 같은 명령으로 편집하고, 한 번에 되돌림
2. 텍스트로 저장되는 그래프와 의사코드 변환
3. 토큰을 아끼는 텍스트 씬과 압축 보기
4. 언어 6종 동시 지원과 자동 생성되는 타입 프록시
5. id 기준 씬 병합으로 사람·에이전트 병렬 작업
