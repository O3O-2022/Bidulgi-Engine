# 비전과 목표

## 한 줄 정의

> 유니티 사용자는 바로 쓸 수 있고, AI 에이전트는 훨씬 적은 토큰으로 다룰 수 있는 범용 게임 엔진.

## 핵심 원칙

1. **사람은 마우스로, AI는 텍스트로, 같은 에디터를 같은 방식으로.**
   에디터의 모든 변경은 명령(Command)으로 처리합니다. UI 버튼, 터미널, AI 에이전트가 같은 명령을 호출합니다.
2. **모든 데이터는 텍스트.** 씬, 프리팹, 설정, UI, 애니메이션을 JSON/TSV/Markdown으로 저장하고 스키마로 검증합니다.
3. **토큰 절약을 설계 단계에서.** 기본값은 저장하지 않고, 파일은 작게 나누고, 읽기는 쿼리로, 쓰기는 패치 명령으로 합니다.
4. **AI가 결과를 스스로 확인할 수 있게.** 헤드리스 렌더링, 시뮬레이션, 자동 테스트를 CLI로 제공합니다.
5. **범용성.** 2D와 3D, 저사양부터 고사양까지, PC·모바일·웹·콘솔.

## 구성 방향: 세 엔진의 장점만

| 출처 | 가져오는 것 |
|---|---|
| **유니티 (겉)** | GameObject/Component 모델, MonoBehaviour 생명주기, Prefab, 에디터 배치와 단축키, C# API 형태 |
| **언리얼 (뼈대)** | RHI 추상화, 스케일러빌리티, 모듈/플러그인 구조, 코드 생성 리플렉션, 플랫폼별 쿠킹, 프로젝트 설정 화면, UMG식 위젯, C++ 매크로 문법 |
| **블렌더 (도구)** | 워크스페이스 탭, 애니메이션 도구 (Dope Sheet, Graph Editor), Python 에디터 자동화 (`bpy`식) |
| **고유 기능** | 텍스트 우선 데이터, 명령 버스, 에이전트 CLI와 MCP 서버, 압축 표기 보기 |

## 차별점 요약

- 유니티 씬 파일(YAML)보다 훨씬 짧은 씬 형식 (기본값 생략, 오브젝트당 한 줄)
- `bdg view`, `bdg query`, `bdg set` 같은 에이전트 전용 명령
- 에디터를 켜 둔 채로 AI가 씬을 바꾸고, Ctrl+Z 한 번으로 되돌리기
- 그래프, C++, C#, Python, Lua 동시 지원 (바인딩 자동 생성)

## 대상 사용자

- 유니티나 언리얼을 써 본 인디 개발자
- AI 에이전트(Claude 등)와 함께 게임을 만들려는 개발자
- 모드 지원이나 다중 플랫폼이 필요한 소규모 팀

## 이름

**비둘기 엔진** (영문 **Bidulgi Engine**) — 2026-11-20 확정

| 쓰는 곳 | 이름 |
|---|---|
| 정식 이름 | 비둘기 엔진 / Bidulgi Engine |
| CLI | `bdg` |
| C++ 매크로 접두어 | `B` (`BCLASS`, `BPROPERTY`, `BFUNCTION`) |
| C API 헤더 | `bdg_api.h` |
| Python 모듈 | `bidulgi` |

- 영문은 "Pigeon" 대신 "Bidulgi"를 씁니다. Pigeon은 이미 여러 개발 도구 이름으로 쓰이고 있어 검색과 상표에서 겹치기 쉽습니다.
- 공개 전에 상표(KIPRIS, USPTO), 도메인, GitHub 이름 확인이 필요합니다.
- 이전 후보: Tessera, Glyph, Scribe, Lattice, Prism, Kiln
