# 2D / 3D 통합

유니티처럼 **하나의 엔진 안에 2D와 3D가 같이** 있습니다. 프로젝트 템플릿과 씬 뷰 모드만 다릅니다.

## 영역별 설계

| 영역 | 공통 | 2D | 3D |
|---|---|---|---|
| Transform | 하나의 Transform | z는 정렬용, 회전은 z축만 | 3축 전체 |
| 카메라 | Camera 컴포넌트 하나 | Orthographic, 픽셀 퍼펙트 옵션 | Perspective / Orthographic |
| 렌더링 | 같은 RHI와 머티리얼 시스템 | SpriteRenderer, Sorting Layer/Order, 배칭 | MeshRenderer, 깊이 버퍼, 라이팅/그림자 |
| 물리 | 같은 충돌 콜백 이름 | Box2D: `Rigidbody2D`, `BoxCollider2D`, `OnCollisionEnter2D` | Jolt: `Rigidbody`, `BoxCollider`, `OnCollisionEnter` |
| 맵 | | Tilemap (청크 단위 텍스트) | Terrain (1.0 이후) |
| 애니메이션 | Animator 상태 머신, 타임라인 공통 | 스프라이트 시트 | 스켈레탈 (glTF) |
| 씬 뷰 | 같은 패널 | [2D] 토글: 정면 고정, 휠 줌 | 자유 카메라 |

- 2D와 3D 물리 월드는 분리되어 서로 충돌하지 않습니다 (유니티와 동일).
- 섞어 쓰기 가능: 3D 월드에 빌보드 스프라이트, 2.5D 게임.
- UI는 별도 위젯 시스템으로 공통 처리 → [ui-widgets](ui-widgets.md)

## 토큰 절약

2D 오브젝트는 값을 줄여서 저장합니다.

```jsonc
{"id":"coin_01", "pos":[4,2], "Sprite":{"img":"coin"}}          // 2D: [x,y], 회전 숫자 1개
{"id":"crate", "pos":[4,0,2], "rot":[0,45,0], "Mesh":{"model":"crate"}}   // 3D
```

## 타일맵

범례와 청크 문자열로 저장합니다. 큰 맵도 AI가 필요한 청크만 읽고 고칠 수 있습니다.

```jsonc
{"id":"ground", "type":"Tilemap", "Tilemap":{
  "palette":{".":null, "#":"stone", "^":"spike"},
  "chunks":{"0,0":["........", "..###...", "########"]}}}
```

- 청크 크기 기본 16×16. LLM은 긴 문자 격자에서 열 위치를 잘 못 세기 때문에 청크를 작게 유지합니다.
- 에디터에는 브러시로 칠하는 타일맵 편집기 제공 (1.0)

- M6 물리: Box2D와 Jolt를 같은 단계에서
