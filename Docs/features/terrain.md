# 지형과 풀·나무 (6라운드, 2026-11-25)

넓은 바깥 장면의 바닥과 그 위의 풀·나무. 유니티 Terrain(높이맵·레이어 칠하기·나무/디테일 칠하기)과 언리얼 Landscape(청크 LOD·레이어·스컬프트 도구)를 따라, 처음 쓰는 사람도 **컴포넌트 하나 + 브러시**로 만들 수 있게 했습니다. 코드는 `Engine/Terrain/`(데이터·그리기·도구·물리), 렌더러 수정 없음.

## 만드는 법

1. 에셋: `.terrain` 파일(아래 형식)과 그 옆의 높이·레이어·풀 맵. C++ `MakeTerrain(...)` + `SaveTerrain(...)`로 만들거나 손으로 씁니다(편집기 메뉴로 새로 만들기는 다음).
2. 오브젝트에 **`Terrain`** 컴포넌트, `asset`에 `Terrain/Hills.terrain`. 오브젝트 위치 = 지형의 (최소 x, 최소 z) 모서리(높이 0), +X·+Z로 `size`만큼. 회전·크기는 무시.
3. Scene 뷰에서 **T(Terrain 도구)**, 지형 위를 끌기. 무엇을 할지는 그 지형의 Inspector **Brush** 칸: `Raise`·`Lower`·`Smooth`·`Flatten`(누른 곳 높이로)·`Paint`(레이어)·`PaintFoliage`·`EraseFoliage`, `brushRadius`(m)·`brushStrength`·`brushLayer`. 커서 자리에 노란 고리.
4. 한 번 끌기 = **Undo 한 번**(명령 `terrain`: 바뀐 영역의 이전·이후 데이터, base64). 놓는 순간 파일에 씀, Undo/Redo도 파일에 씀.

## 파일 형식

```jsonl
{"terrain":"Hills","resolution":257,"size":[200,200],"height":40,"heightmap":"Hills.height.r16","splatmaps":["Hills.splat0.png"],"foliagemap":"Hills.foliage.png"}
{"layer":"Grass","color":[0.32,0.45,0.18],"roughness":0.9,"texture":"Textures/grass.png","tiling":4}
{"layer":"Rock","color":[0.45,0.43,0.40],"roughness":0.8}
{"foliage":"Grass","kind":"grass","density":6,"layer":0,"scale":[0.6,1.2],"fade":[25,35],"maxSlope":35,"color":[0.35,0.55,0.2]}
{"foliage":"Trees","kind":"tree","density":0.01,"layer":-1,"scale":[0.8,1.4],"fade":[160,200],"impostor":70}
```

| 파일 | 내용 |
|---|---|
| `Hills.terrain` | 머리 줄(해상도 2^n+1: 33…4097, 크기 m, 최고 높이 m, 맵 파일 이름) + 레이어 줄(최대 8) + 풀·나무 줄(최대 4) |
| `Hills.height.r16` | 해상도² 개 16비트(리틀 엔디언), 0 = 바닥, 65535 = 최고 높이 |
| `Hills.splat0.png` (`splat1`) | 레이어 무게, RGBA 하나에 레이어 4개(합 255) |
| `Hills.foliage.png` | 풀·나무 층별 밀도(RGBA = 층 1~4), 255 = 설정한 밀도 그대로 |

텍스처가 있는 레이어의 `color`는 곱하는 색(0.5 회색 = 텍스처 그대로). 맵 파일 이름이 머리 줄에 있어 "쓰는 곳 찾기"와 `bdg build`의 안 쓰는 에셋 빼기가 맵을 지우지 않습니다.

## 그리기

- **청크 LOD**: 32×32 칸 청크, 카메라와의 거리로 LOD(`lodDistance` 안 = 전부, 거리가 두 배마다 절반). 청크마다 아래로 드리운 **스커트**가 LOD가 다른 이웃 사이의 틈을 가림(검사: 바로 위에서 내려다봐도 하늘이 안 보임). 화면 밖 청크는 그리지 않음.
- **레이어**: 레이어 텍스처 × 색을 지형 전체 **색 맵**·**거칠기 맵**으로 구움(밉맵). 경사가 가파른 곳은 **트라이플래너**(세 방향 투영, 보통 이상). 칠하면 칠한 부분만 다시 구움.
- 지형·풀·나무는 렌더러에 **보통 그리기 항목**으로 넘어가서 조명·그림자·안개·TAA·인스턴싱을 그대로 받음(렌더러 파일 수정 없음).
- **풀**: 잎 세 장 묶음, **나무**: 줄기 + 원뿔 두 개 — LOD 0(자세히)·LOD 1(`impostor`의 절반부터, 간단히)·LOD 2(`impostor`부터 카메라를 보는 **카드**, 나무 옆모습을 그린 알파 텍스처). 같은 메시끼리 한 번에(인스턴싱).
- **뿌리기**: 청크·층마다 시드가 정해진 위치 — 같은 데이터면 같은 풀(한 곳을 지워도 다른 풀은 그대로). 밀도 맵 × (층이 정한 레이어의 무게) × 경사(`maxSlope`)로 남김.
- **거리**: `fade` 사이에서 작아지며 사라짐, 가까운 청크부터 단계 예산까지. 화면 밖·페이드 밖 청크는 뿌리지도 않음.
- **바람**: 아래는 그대로, 위가 옆으로 흔들림(`Terrain.wind`, 0 = 멈춤).

## 품질 단계 (`TerrainTier`)

| 단계 | LOD 거리 | 색 맵 | 트라이플래너 | 풀 밀도 | 나무 밀도 | 페이드 거리 | 풀 / 나무 예산 | 바람 |
|---|---|---|---|---|---|---|---|---|
| 최소 | ×0.5 | 256 | 끔 | 0 (없음) | ×0.5 | ×0.5 | 0 / 300 | 끔 |
| 낮음 | ×0.75 | 512 | 끔 | ×0.2 | ×0.75 | ×0.7 | 4,000 / 800 | 켬 |
| 보통 | ×1 | 1024 | 켬 | ×0.5 | ×1 | ×1 | 15,000 / 2,000 | 켬 |
| 높음 | ×1.5 | 2048 | 켬 | ×1 | ×1 | ×1.5 | 40,000 / 4,000 | 켬 |
| 최고 | ×2 | 2048 | 켬 | ×1 | ×1 | ×2 | 80,000 / 8,000 | 켬 |

**비용**(검사 로그, 이 PC GPU, 128 m 지형 129² 샘플·풀 3/m²·나무): 최소 5,504 삼각형·풀 0·CPU 0.2 ms, 보통 17,664·풀 1,933·0.3 ms, 최고 28,672·풀 15,956·1.5 ms. 색 맵 굽기 1024² ≈ 180 ms(불러올 때 한 번, 칠할 때는 칠한 부분만). GPU 시간은 장면 패스에 포함(통계 패널·예산 막대의 삼각형·그리기 수에 지형과 풀이 들어감). CI 로그에 단계별 수치를 `::notice::`로 남김.

## 물리와 스크립트

- `Terrain.collider`(기본 켬): 플레이할 때 **Jolt HeightFieldShape** 정적 몸체(PHI `ShapeKind::HeightField`). 캐릭터·물체가 지형 위에 섬, 레이캐스트(`Physics.Raycast`, 발 IK)도 맞음.
- C#: `Terrain.HeightAt(x, z)`(지형 밖 = NaN), `Terrain.TryHeightAt(x, z, out h)`, `Terrain.NormalAt(x, z)` / `(Vector3)` — 엔진 요청 `terrain.height`.

## 검사

- 단위 테스트(`Tests/TerrainTests.cpp`): 저장·읽기 왕복, 높이·법선(경사로 값), 지형 레이캐스트, 브러시 7가지(올림 범위·평탄화 목표·스무딩·레이어 합 255·밀도), 청크 메시(정점 수·감김·스커트), **LOD 경계 틈 < 스커트 깊이**, LOD 거리, 단계 값, 뿌리기(시드·밀도·레이어·지우기 후 남은 풀 위치 그대로), `terrain` 명령(영역·Undo·Redo·파일·범위 밖 거부), 높이 필드 위에 멈춘 공과 레이캐스트, 빌드가 맵 파일을 지우지 않음.
- `BDG_TERRAIN_TEST`(편집기): 렌더·LOD 여러 개·컬링, 위에서 내려다볼 때 하늘 0(틈 없음), 브러시로 올리기(높이 6.0 → 8.1 m)·Undo/Redo, 레이어 칠하기(색 바뀜, 그 자리 풀 1,372 → 177), 단계별 삼각형·풀·ms, 플레이 중 C# `TerrainProbe` 캡슐이 `HeightAt` 자리에 섬 → `terrain test: render=1 lods=1 cracks=1 sculpt=1 undo=1 paint=1 foliage=1 tiers=1 stand=1`.
- `BDG_FOLIAGE_TEST`(편집기): 풀·나무 LOD 0/1/카드, 바람(두 시각 그림이 다름 / 바람 0이면 같음), 높이서 보면 풀 사라지고 나무는 카드만, 반대로 보면 청크·풀 컬링, 낮음 풀 예산 → `foliage test: plants=1 lods=1 wind=1 calm=1 fade=1 culled=1 budget=1`.

## 남은 것

- 편집기: 새 지형 만들기 메뉴, 브러시 단축키(크기 `[` `]`), 높이맵 가져오기(PNG16·RAW)·내보내기, 구멍(동굴 입구), 여러 지형 이어 붙이기, 브러시 모양 텍스처.
- 그리기: 클립맵/CDLOD 모핑(LOD가 바뀔 때 튐 없이), GPU 테셀레이션·디테일 노멀, 레이어 노멀·높이 블렌드(지금은 구운 색 한 장), 가상 텍스처(아주 큰 지형), 풀 GPU 생성(지금은 CPU가 항목을 만듦)·알파 텍스처 풀잎, 나무 메시 에셋(지금은 내장 모양)·찍어서 만드는 임포스터, 그림자 거리별 풀 그림자 끄기.
- 물리: 레이어별 물리 재질(마찰·발소리), 플레이 중 지형 수정 반영.
