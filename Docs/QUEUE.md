# 작업 대기열

**만들 순서대로** 적은 목록입니다. 새 대화(사람이든 AI든)는 이 파일부터 읽고, 맨 위의 `[ ]` 항목 하나를 집어 진행합니다.

## 사용 규칙

- 상태: `[ ]` 대기 · `[~]` 진행 중 · `[x]` 완료 · `[-]` 취소/보류
- 한 번에 **하나만** `[~]`로 둡니다. 끝나면 `[x]`로 바꾸고 날짜와 결과(커밋, 파일)를 한 줄 적습니다.
- 항목마다 **완료 조건**이 있습니다. 조건을 실제로 확인한 뒤에만 `[x]`로 바꿉니다.
- 순서를 바꾸거나 항목을 추가하면 [decisions](planning/decisions.md)에 이유를 한 줄 남깁니다.
- 큰 계획은 [roadmap](planning/roadmap.md), 세부 기획은 각 문서. 이 파일은 "다음에 뭘 하나"만 다룹니다.
