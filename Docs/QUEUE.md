## 0. 새 작업자 시작 안내 (먼저 읽기)

### 프로젝트 한 줄 요약
AI 친화적이고 텍스트 기반인 범용 게임 엔진. 겉은 유니티, 속은 언리얼, 도구는 블렌더식. C++20, MIT 라이선스.
기획 전체는 [README](README.md)에서 시작합니다. 확정된 결정은 [decisions](planning/decisions.md)에 있습니다.

### 빌드 (Windows)
필요한 것: Visual Studio 2022 (C++ 데스크톱 워크로드), CMake 3.24 이상, Python 3, git, 인터넷(첫 구성 때 SDL3·FreeType·yyjson을 받음). C# 스크립팅(M4)에는 .NET 8 이상 SDK(`dotnet`) — 없으면 엔진은 빌드되고 C#만 빠짐.

```powershell
# CMake가 없으면 둘 중 하나: VS Installer에서 "C++용 CMake 도구" 추가, 또는
python -m pip install --user cmake
# 구성 + 빌드 (저장소 루트에서)
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --target BidulgiEditor
# 실행: 빌드가 끝나면 Bin/BidulgiEditor.exe로 자동 복사됨
.\Bin\BidulgiEditor.exe
```
- 경고 0개를 유지합니다 (`/W4`). 외부 라이브러리 경고는 해당 타깃에서만 끕니다. **CI(`.github/workflows/ci.yml`)가 매 푸시·PR마다 빌드와 자동 테스트를 돌립니다** — 새 자동 테스트를 만들면 CI의 Smoke tests 단계에도 추가하세요.
- glad 로더를 다시 만들 때: `python -m pip install --user glad2` 후 `ThirdParty/glad/README.md`의 명령.

## 나중 — 게임 모드 지원 (사용자 계획, 2026-11-25)

비둘기 엔진으로 만든 **게임**이 모드를 받을 수 있게 한다. 지금 당장 만들지 않지만, 아래 "지금부터 지킬 것"은 모든 레인이 지킨다.

**지금부터 지킬 것 (모드를 막지 않게)**
- 게임 데이터는 계속 텍스트(JSONL·JSON·.material·.animgraph·.vfx·테이블)로, 경로·GUID로만 서로 참조한다(코드에 하드코딩한 에셋 경로 금지).
- `.bpak` 읽기는 "여러 팩을 순서대로 덮어 쓰는" 가상 파일 시스템을 거친다(지금은 팩 1개여도 그 길로).
- C# 게임 API(Easy·Events·Physics·Save 등)는 공개 API로 보고, 바꿀 때는 이전 이름을 한동안 남긴다.
- 멀티플레이(7라운드)는 접속할 때 양쪽의 콘텐츠 목록(팩·모드 이름과 해시)을 비교할 자리를 남긴다.

**나중에 만들 것 (MOD-1 ~)**
- [ ] **MOD-1. 모드 폴더와 매니페스트** — `Mods/<이름>/mod.json`(이름·버전·작성자·게임 버전 범위·의존성·충돌), 불러오는 순서, 켜고 끄기 목록.
- [ ] **MOD-2. 데이터 덮어쓰기·추가** — 모드의 에셋이 같은 경로의 원본을 가리거나 새로 추가, 테이블은 행 단위 병합(JSONL 패치).
- [ ] **MOD-3. 스크립트 모드** — Lua(Luau) 샌드박스가 기본(파일·네트워크 접근 없음, 실행 시간 제한), 신뢰한 모드만 C# 어셈블리.
- [ ] **MOD-4. 모드 SDK** — `bdg mod new / pack`, 에디터에서 "모드 프로젝트"로 게임 에셋을 읽기 전용으로 열기, 검증(`bdg mod check`).
- [ ] **MOD-5. 게임 안 모드 메뉴** — 목록·켜고 끄기·순서·충돌 표시, 세이브에 사용한 모드 기록.
- [ ] **MOD-6. 배포** — Steam Workshop·mod.io 연동(선택), 멀티플레이에서 서버 모드 목록 동기화.
