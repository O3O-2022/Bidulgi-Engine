# 물리 — 바꿔 끼우는 CPU·GPU 물리

작성 2026-11-21. 목표: **물리 엔진을 프로젝트마다 바꿀 수 있고**, CPU 물리와 GPU 물리를 함께 써서 복셀 파괴 게임, 오픈월드, 대규모 시뮬레이션을 만들기 쉽게 합니다.

## 구조: 물리 추상 계층 (렌더링의 RHI와 같은 방식)

```
 게임 코드·Graph·에디터  ──  Rigidbody, Collider, Joint, Query (백엔드와 무관한 컴포넌트)
                              │
                     Physics Interface (PHI)
        ┌───────────────┬──────────┴─────────┬──────────────────┐
     Jolt (3D, CPU)   Box2D (2D, CPU)   GPU 물리 (자체, 컴퓨트)   추가 백엔드 (패키지)
     기본값             2D 기본값          복셀·파편·천·유체      예: PhysX 5, 자작 엔진
```

| 백엔드 | 용도 | 플랫폼 | 일정 |
|---|---|---|---|
| **Jolt Physics** | 3D 강체, 캐릭터, 차량, 래그돌. 결정론 옵션, 배정밀도 좌표 지원 | 전부 | 1.0 |
| **Box2D v3** | 2D 물리 | 전부 | 1.0 |
| **GPU 물리 (자체)** | 복셀 파괴, 대량 파편, 입자, 천, 유체(위치 기반 동역학 PBD) | 컴퓨트 셰이더가 되는 기기 (SDL_GPU, 고사양 이상) | L 트랙 |
| 패키지 백엔드 | PhysX 5(BSD-3, GPU 기능은 NVIDIA 전용) 등 | 백엔드마다 다름 | 패키지로 누구나 |

## 바꿔 끼우기 규칙

- 씬과 프리팹에는 **백엔드와 무관한 값만** 저장합니다(질량, 마찰, 모양, 관절). 백엔드 전용 값은 선택 섹션(`"jolt":{...}`)에 둡니다. 백엔드를 바꿔도 씬 파일은 그대로입니다.
- 백엔드는 프로젝트 설정에서 고르고, **월드나 레이어 단위로 섞을 수 있습니다.** 예: 캐릭터·차량은 Jolt, 부서진 파편은 GPU 물리.
- 백엔드마다 가능한 기능을 표로 선언합니다(능력 플래그). 지원하지 않는 기능을 쓰면 에디터와 `bdg validate`가 알려 줍니다.
- 백엔드끼리의 상호작용(예: Jolt 강체가 GPU 파편을 밀어냄)은 경계 결합 단계에서 한 프레임 단위로 주고받습니다.
- 새 백엔드는 C API로 구현하는 플러그인입니다. 같은 테스트 장면 모음(쌓기, 관절, 연속 충돌, 결정론)을 통과해야 목록에 올라갑니다.

```
$ bdg physics backends
jolt     3D  cpu  deterministic  double-precision   기본
box2d    2D  cpu  deterministic                      2D 기본
gpu      3D  gpu  voxel debris cloth fluid           high 이상
```

## 복셀 파괴

| 단계 | 처리 | 어디서 |
|---|---|---|
| 데이터 | 청크(32³) 희소 저장. 복셀마다 재질 번호, 재질은 강도·밀도·파괴 방식 | CPU 원본, GPU 사본 |
| 피해 | 폭발·총탄·도구가 복셀을 지우거나 약하게 함. **편집은 명령**으로 기록 (Undo, 네트워크, 재생) | GPU |
| 연결 검사 | 지지 구조를 따라 떨어진 덩어리(섬) 찾기 | GPU 컴퓨트 |
| 떨어진 덩어리 | 큰 것은 Jolt 강체(복셀 충돌체), 작은 것은 GPU 파편 입자, 아주 작은 것은 이펙트 | Jolt + GPU |
| 메시 | 바뀐 청크만 다시 메시화 (블록형: greedy meshing, 매끈형: surface nets) | GPU |
| 저장 | 원본 복셀은 바이너리 청크, 바뀐 내용은 편집 기록으로. 씬 JSONL에는 참조만 | — |

- 성능 목표 (고사양): 한 번에 복셀 10만 개 파괴, 동시 파편 5만 개를 60fps 안에.
- 낮은 단계 기기: 파편 수를 줄이고 작은 파편은 이펙트로 대체합니다. 게임 결과(어디가 부서졌는가)는 단계와 상관없이 같습니다.
- 멀티플레이: 파편 모양이 아니라 **복셀 편집 명령**만 동기화합니다. 게임에 영향을 주는 덩어리는 결정론 Jolt로, 보기용 파편은 각자 계산합니다.

## 오픈월드와 복잡한 게임

- **큰 좌표:** Jolt 배정밀도 빌드 + 렌더링은 카메라 기준 좌표. 수십 km 맵에서 떨림이 없게 합니다.
- **스트리밍:** 월드 파티션 셀 단위로 물리 데이터를 올리고 내립니다. 멀리 있는 물체는 잠들게 하거나 간단 시뮬레이션으로 바꿉니다.
- **결정론:** Jolt 결정론 옵션으로 리플레이, 롤백 넷코드, 자동 테스트를 지원합니다.
- **스레드:** 물리는 잡 시스템 위에서 돌고, 게임 코드에는 프레임 순서의 정해진 시점에 결과를 넘깁니다 ([interop](interop.md)).
- **진단:** `bdg physics diagnose <씬>` → 깨어 있는 물체 수, 비싼 충돌체, 끼임 의심, 단계별 시간을 텍스트로.
