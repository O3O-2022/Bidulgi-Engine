# 렌더링과 플랫폼

목표: **저사양부터 고사양까지, PC·모바일·웹·콘솔.**

## RHI (Render Hardware Interface)

엔진 코드는 그래픽 API를 직접 부르지 않고 RHI만 사용합니다 (언리얼 방식).
처음에는 OpenGL로 빠르게 개발하고, 나중에 백엔드만 추가합니다.

| 플랫폼 | 필요한 그래픽 API | 백엔드 상태 |
|---|---|---|
| 일반 PC (Windows/Linux) | OpenGL 4.5 | **첫 구현** |
| 저사양 PC, 구형 Android | OpenGL ES 3.0 | 2순위 |
| 웹 | WebGL2 | 2순위 |
| 고사양 PC | Vulkan, D3D12 → **SDL_GPU 백엔드**로 한 번에 | 1.0 이후 |
| iOS, macOS | Metal → **SDL_GPU 백엔드** (Apple은 OpenGL을 사실상 중단) | 1.0 이후 |
| Xbox | D3D12 | 계약 후 |

> 두 번째 백엔드는 Vulkan·Metal·D3D12를 각각 만들지 않고 **SDL_GPU 하나**로 만듭니다. 셰이더는 한 언어로 쓰고 빌드 때 SPIR-V·MSL·DXIL로 변환합니다. 1.0의 그래픽 목표(스타일라이즈드·모바일·인디 중고급)와 품질 경로는 [risk-response](../planning/risk-response.md#4-고급-그래픽이-약함--경쟁하지-않는-영역을-정하고-중급-품질을-확실히)에 있습니다.
| PlayStation, Switch | 전용 API (**제조사 개발자 계약과 NDA 필요**) | 계약 후 비공개 포트 |

## 렌더 그래프와 렌더 경로

```
            ┌──────────── Render Graph ────────────┐
            │  패스를 선언하면 RHI가 순서·자원 관리   │
            └──────┬──────────────┬────────────────┘
   감자: Unlit 2D 배칭   저·중사양: Forward   고사양: Forward+   초고사양: Forward+ / Deferred
                  └──────── 품질 단계 설정으로 자동 전환 ────────┘
```

## 품질 단계 (5단계, 2026-11-21 확정)

언리얼의 스케일러빌리티처럼 설정을 그룹으로 묶되, 단계를 **감자 · 저사양 · 중사양 · 고사양 · 초고사양** 다섯 개로 나눕니다. 설정 키는 `potato`, `low`, `medium`, `high`, `ultra`입니다.

### 단계의 뜻

| 단계 | 한 줄 정의 | 대표 게임 | 대상 기기 (목표) | 목표 프레임 |
|---|---|---|---|---|
| **감자** (`potato`) | 그래픽 연산을 거의 쓰지 않음. 그림자·조명 없는 2D 위주 | 픽셀 아트, 퍼즐, 카드, 비주얼 노벨 | 아주 오래된 휴대폰·PC, 저가 태블릿, 웹 | 60fps (고정 화면은 필요할 때만 그림) |
| **저사양** (`low`) | 옛날 기기에서도 돌아감 | 가벼운 3D, 조명 있는 2D | 출시 7~8년 지난 휴대폰, 내장 그래픽 노트북 | 30fps 이상 |
| **중사양** (`medium`) | **모든 지원 플랫폼에서 안정적으로** 돌아감 (기본값) | 일반적인 인디 3D, 모바일 3D | 보급형 휴대폰, 일반 PC, 웹 | 30~60fps 안정 |
| **고사양** (`high`) | 여러 플랫폼에서 30~60fps 이상, 그래픽도 좋음 | 중대형 3D, 스타일라이즈드 고품질 | 최신 중급 이상 휴대폰, 게이밍 PC, 콘솔급 | 60fps (모바일 30fps 이상) |
| **초고사양** (`ultra`) | 루멘급 실시간 GI 등 최고 품질 | 고품질 3D, 오픈월드 | 고사양 게이밍 PC, 레이 트레이싱 GPU | 30~60fps |

### 단계별 설정

| 그룹 | 감자 | 저사양 | 중사양 | 고사양 | 초고사양 |
|---|---|---|---|---|---|
| 렌더 경로 | Unlit 2D (스프라이트 배칭만) | Forward, 정점 라이팅 | Forward, 픽셀 라이팅 | Forward+ (클러스터 라이트) | Forward+ / Deferred |
| 조명 | 없음 (스프라이트 색 그대로) | 라이트 4개, 정점 단위 | 라이트 8개 | 다수 (클러스터) | 다수 + 면광원 |
| 전역 조명 (GI) | 없음 | 라이트맵만 (저해상도) | **Halo GI Tier 0** (라이트맵 + 프로브) | **Tier 1** (동적 프로브) | **Tier 2~3** (래디언스 캐스케이드, HW RT) |
| 그림자 | 없음 | 없음 또는 블롭(동그란 바닥 그림자) | 그림자 1단계 | CSM 3 + 소프트 | CSM 4 + 접촉 그림자 |
| 텍스처 | 원본 (2D) / 최대 512 | 1/4 해상도 | 1/2 | 원본 | 원본 + 이방성 16x |
| 포스트 프로세스 | 없음 | 없음 | 톤매핑, FXAA | + Bloom, SSAO, 컬러 그레이딩 | + TAA, 볼류메트릭, SSR |
| 이펙트(파티클) | 최소 | 최소 | 기본 | 기본 | 고밀도 |
| 뷰 거리 | — | 0.5 | 0.75 | 1.0 | 1.25 |
| 그래픽 API | GLES 3.0 / WebGL2 | GLES 3.0 / WebGL2 | GLES 3.0 / WebGL2 / GL 4.5 | GL 4.5 · SDL_GPU | SDL_GPU (Vulkan·D3D12·Metal) |

### 규칙

- **2D 게임은 감자 단계로 만들면 대부분의 기기에서 돌아갑니다.** 2D 조명이나 그림자를 쓰면 자동으로 저사양 이상 기능을 쓰는 것으로 표시됩니다.
- **중사양이 기본값**입니다. "모든 플랫폼에서 안정적"이 엔진의 기본 약속입니다.
- 게임은 **최소 단계**와 **최대 단계**를 정합니다 (예: 최소 저사양, 최대 고사양). 최소 단계 아래 기기에는 설치·실행 시 안내합니다.
- 기기 성능을 측정해 자동으로 단계를 고르고, 실행 중 프레임이 계속 떨어지면 한 단계 내리는 동적 조정 옵션이 있습니다 (모바일 발열 대응).
- 같은 장면을 모든 단계에서 씁니다. 아티스트는 장면을 한 번만 만들고, 단계별로 빠지는 기능은 엔진이 대체합니다 (예: 그림자 없음 → 블롭 그림자).
- 편집 중 플랫폼 예산 표시는 **선택한 단계 기준**으로 막대를 보여 줍니다 ([아래](#편집-중-플랫폼-예산-표시)).
- 플랫폼별 기본 단계와 최소·최대 단계는 프로젝트 설정에서 지정합니다 → [project-settings](../features/project-settings.md)
- 오래된 기기를 더 넓게 지원하려면 감자·저사양에 GLES 2.0 / WebGL1 백엔드를 추가하는 안을 1.0 이후에 검토합니다.

## 에셋 쿠킹

에디터는 원본(PNG, glTF, WAV)을 쓰고, 빌드 때 플랫폼에 맞게 변환합니다.

| 대상 | 텍스처 | 메시 | 오디오 |
|---|---|---|---|
| PC | BC7 | 최적화된 바이너리 | Vorbis |
| Android / iOS | ASTC | LOD 축소 | Vorbis / AAC |
| 웹 | KTX2 (Basis) | 압축 | Opus |

- 쿠킹 결과는 `.cache/`에 저장하고, 원본 텍스트 데이터와 섞지 않습니다.

## 플랫폼 레이어

- 창, 입력, 파일 시스템, 스레드, 타이머를 플랫폼별로 구현합니다.
- 데스크톱은 GLFW, 모바일은 각 OS의 네이티브 API, 웹은 Emscripten.
- macOS는 OpenGL이 4.1에서 멈춰 있어서 Metal 백엔드 전까지는 제한적으로 지원합니다.

## 편집 중 플랫폼 예산 표시

에디터 뷰포트 구석에 **대상 플랫폼의 예산 막대**를 띄웁니다. 실행해서 프로파일링하기 전에, 배치하는 순간 넘친 것을 알 수 있습니다.

```
Android · Medium            Draw   ███████████░░  182 / 200
                            Tris   ████████████▌  1.18M / 1.0M  ⚠
                            텍스처  ██████░░░░░░░  310 / 512 MB
                            라이트  ███░░░░░░░░░░  3 / 8 (그림자 1 / 2)
```

- 예산 값은 플랫폼·Device Profile별로 프로젝트 설정에서 정합니다 (기본값 제공).
- 막대가 넘치면 원인 상위 오브젝트를 Hierarchy와 뷰포트에서 강조하고, 클릭하면 선택됩니다.
- 수치는 현재 카메라 기준 추정치입니다. 정확한 값은 해당 기기에서 `bdg profile`로 확인합니다.
- 텍스트로도 볼 수 있습니다: `bdg budget forest_01 --platform Android` (AI가 레벨을 수정한 뒤 확인하는 용도).

## 전역 조명 (GI)

단계별 하이브리드 GI(가칭 Halo GI)를 씁니다. 1.0은 Tier 0(라이트맵 + 프로브 볼륨)이고, 실시간 GI는 SDL_GPU 렌더러 이후 단계적으로 추가합니다. → [global-illumination](../features/global-illumination.md)
