# {{GAME_NAME}} — guide for AI agents (and people)

Made from the Bidulgi Engine **third-person template** (`bdg new <dir> --template thirdperson`).
비둘기 엔진 **3인칭 템플릿**으로 만든 프로젝트입니다.

## 이 템플릿 구조와 고치는 법 (Template structure and how to change it)

```
Scenes/Main.scene                     the playground: ground, walls, stairs + landing, ramp + deck, crates, a beacon,
                                      the player, the camera, the HUD (one line = one object)
Assets/Player/ThirdPersonController.cs  walk / run relative to the camera, turn, step up, jump, wave; sets the Animator's
                                      Speed / Jump / Wave and the head's look-at; writes the HUD
Assets/Camera/FollowCamera.cs         orbit with Look, pull in when a wall is between (Physics.Raycast)
Assets/Models/Hero.gltf               the character: generated by `bdg new` (CC0), 17 bones, clips Idle, Walk, Run,
                                      WalkBack, StrafeLeft, StrafeRight, Jump, Wave, LeanAdd. Replace it with your own
                                      glTF / FBX character with the same clip names (or change the graph).
Assets/Anim/Hero.animgraph            the animation graph (text): Move = blend space on Speed (Idle 0, Walk 1.6, Run 5),
                                      Strafe = 2D blend space on MoveX / MoveY, Jump; layers UpperBody (Wave, override
                                      from RightUpperArm, weight = Wave variable) and Lean (additive on the spine)
Assets/Audio/Jump.wav                 generated sound (CC0)
Input/Actions.jsonl, Input/Contexts/OnFoot.jsonl   Move, Look, Jump, Sprint, Wave and their keys / gamepad buttons
ProjectSettings/Project.json          name, version, start scene, window
Game.csproj                           builds Assets/**/*.cs into .cache/Scripts/
```

The player is `Player` (Rigidbody **Character** + capsule Collider + `ThirdPersonController`) → child `Hero`
(MeshRenderer + `Animator` + `AnimatorIK`). The capsule moves; `Hero` only turns and animates. `AnimatorIK` keeps the
feet on the ground (stairs, ramp) with physics raycasts and turns the head towards `LookAt` (the controller sets it to
the beacon when near). `Camera` has `FollowCamera` (target `Player`).

## 자주 하는 변경 (Common changes)

- 걷기·달리기 속도: `ThirdPersonController` walkSpeed / runSpeed (Inspector) — 그래프의 Walk / Run 샘플 x와 맞추면 발이 미끄러지지 않습니다.
- 다른 캐릭터: Models/에 glTF/FBX를 넣고 Hero의 MeshRenderer.mesh를 바꿉니다. 뼈 이름이 다르면 AnimatorIK의 leftFoot / rightFoot / head를 고칩니다.
- 상태 추가: Anim/Hero.animgraph의 states / transitions (조건 `"when":"Speed > 3 && !Strafe"`), C#에서 `animator.SetFloat` / `SetTrigger`.
- 죽을 때 래그돌: Hero에 `Ragdoll` 컴포넌트를 더하고 C#에서 `Game.Get<Ragdoll>(hero)?.Activate()`.
- 카메라: `FollowCamera` distance / height / sensitivity.
