Why Bidulgi

익숙한 사용법, AI까지 생각한 구조

유니티의 화면과 개념, 언리얼의 엔진 구조, 블렌더의 애니메이션 도구를 모았습니다. 여기에 AI가 적은 토큰으로 정확하게 작업할 수 있는 데이터 구조를 더했습니다.

사람과 AI가 같은 명령으로

버튼을 누르든, 터미널에 쓰든, AI가 보내든 모두 같은 명령 버스를 거칩니다. AI가 한 작업도 Ctrl+Z 한 번으로 되돌립니다.

bdg set g1 Health.hp=40 pos=6,0,4

토큰을 아끼는 텍스트 데이터

기본값은 저장하지 않고, 오브젝트 하나를 한 줄로 씁니다. git에서 줄 단위로 비교·병합되고, AI는 필요한 줄만 읽습니다.

{"id":"g1", "prefab":"prefabs/goblin.prefab", "pos":[6,0,1]}

차세대 그래프 스크립팅

언리얼 블루프린트와 같은 구조에, 텍스트 저장과 빠른 레지스터 VM을 더했습니다. 그래프를 의사코드로 읽고, 의사코드로 그래프를 만듭니다.

on Update: if Distance(target) < 2: Attack()

한 엔진, 여러 언어

C#은 유니티 문법, C++은 언리얼 매크로, 그래프는 언리얼 블루프린트 구조, 가벼운 로직은 Lua, AI와 도구는 Python. 그래프를 고치면 코드용 타입이 자동으로 생성됩니다.

public class Goblin : MonoBehaviour { ... }

FAQ

자주 묻는 질문

무료인가요?

라이선스는 아직 정하지 않았습니다. 오픈소스 공개를 검토하고 있으며, 프리뷰 공개 전에 알려 드립니다.

AI 없이도 쓸 수 있나요?

네. 모든 기능은 마우스와 키보드로 쓸 수 있습니다. AI 연동은 같은 일을 텍스트 명령으로도 할 수 있게 열어 둔 것입니다.

유니티 프로젝트를 옮길 수 있나요?

모델, 텍스처, 오디오, 머티리얼 기본값, 프리팹 계층은 가져오기 도구로 옮길 수 있게 할 계획입니다. C# 스크립트는 API가 비슷한 부분부터 변환을 제안합니다. 완전 자동 변환은 아닙니다.

언리얼 블루프린트를 그대로 가져올 수 있나요?

아닙니다. 구조와 개념이 같아서 익숙하게 쓸 수 있지만, 저장 형식이 달라 파일을 그대로 열 수는 없습니다.

오픈월드나 대형 FPS도 만들 수 있나요?

1.0은 인디 규모, 스타일라이즈드, 모바일·웹 게임에 맞춰 범위를 정했습니다. 대형 월드 스트리밍, 고급 렌더링, 멀티플레이어는 1.0 이후 로드맵에 있습니다.

macOS에서 쓸 수 있나요?

1.0은 Windows 에디터만 제공합니다. macOS·iOS는 두 번째 그래픽 백엔드(SDL_GPU)를 붙인 뒤 지원할 계획입니다.
